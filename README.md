# Aniversario da Hilary

Cartao animado em HTML, CSS e JavaScript.

Fluxo do site (todos os arquivos ficam na mesma pasta):

1. `index.html` — mini jogo (página inicial, abre primeiro no GitHub Pages)
2. `pergunta.html` — pergunta de confirmação (acessada ao vencer o jogo)
3. `cartao.html` — cartão de aniversário final (acessado ao responder "Sim")

Para alterar a meta do jogo, edite a constante `GOAL` em `game.js`.
